# Poshak Fabrics 🌟

**Poshak Fabrics** is a premium e-commerce platform dedicated to offering the finest ethnic wear, stitched, and unstitched clothing collections across Pakistan. The application features a modern, responsive user interface built with Next.js and a robust backend powered by Node.js, Express, and PostgreSQL.

---

## ✨ Features

- **Modern Shopping Experience:** Responsive and elegant UI with dynamic product displays and cart management.
- **Advanced Authentication:** Secure Email/Password registration and **Continue with Google** integration.
- **AI-Powered Chatbot:** Built-in intelligent assistant using Google's Gemini GenAI to help customers with their shopping experience.
- **High-Performance Caching:** Upstash Redis integration for lightning-fast user data retrieval and database offloading.
- **Automated Email Notifications:** Welcome emails and order confirmations handled asynchronously via Nodemailer.
- **Admin Dashboard:** Secure backend access to manage users, products, and incoming orders.
- **Media Management:** Seamless image storage and retrieval using Cloudinary.

---

## 🛠️ Tech Stack

### Frontend
- **Framework:** Next.js 16 (App Router)
- **Library:** React 18
- **Styling:** TailwindCSS v4
- **Icons:** Lucide React & React Icons
- **Authentication:** `@react-oauth/google`

### Backend
- **Runtime:** Node.js
- **Framework:** Express.js
- **Database:** PostgreSQL (via `pg`)
- **Caching:** Upstash Redis
- **Authentication:** JWT (JSON Web Tokens), bcrypt, `google-auth-library`
- **AI Integration:** `@google/genai`
- **File Uploads & Storage:** Multer & Cloudinary
- **Emails:** Nodemailer
